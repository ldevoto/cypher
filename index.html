Cómo funciona y formato del texto cifrado

La clave maestra se convierte en una clave de 256 bits con PBKDF2 y una sal aleatoria de 16 bytes. Cada cifrado usa un IV/nonce aleatorio nuevo, así que cifrar dos veces el mismo texto da resultados distintos. Los tres modos están autenticados: si alguien altera un solo carácter del texto cifrado, o la clave es incorrecta, el descifrado falla en vez de devolver basura.

Formato: Base64URL de [sal (16 bytes), IV (16 bytes), datos cifrados]. No hay cabecera ni marcas: los tres algoritmos producen salidas del mismo largo y que parecen bytes aleatorios, así que no se puede saber cuál se usó. El texto se rellena a bloques de 32 bytes para no revelar su largo exacto. Las iteraciones de PBKDF2 se eligen entre 100.000 y 10.000.000 y tampoco quedan guardadas. Usa solo la Web Crypto API del navegador, sin librerías externas.
